# Asset and dependency provenance

All HOLLOW//30 character meshes, outfits, weapon finishes, environment geometry, map layout, textures, particles, UI graphics, icons and audio are original code-created assets in this repository. There are no third-party model/image/audio/font requests. System fonts are used. Textures are generated with Canvas, meshes with Three.js primitives, sound with the Web Audio API.

Runtime dependencies:
- Three.js: MIT, https://github.com/mrdoob/three.js/blob/dev/LICENSE
- ws: MIT, https://github.com/websockets/ws/blob/master/LICENSE

Test dependency:
- Playwright: Apache-2.0, https://github.com/microsoft/playwright/blob/main/LICENSE

The backed-up prior website in `original-site/` is not served by the game. Its old external image/font references are outside this game’s asset set.
